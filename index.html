Sobre a Galeria de Arquitetura

Este repositório contém Provas de Conceito (PoCs) e validações de cenários de nível Enterprise focados na Nuvem AWS. Cada projeto destaca decisões de segurança, governança multi-conta e otimização de custos nativa.

FinOps & SCP

01. FinOps Budget Enforcement

Detecção e bloqueio automático corporativo contra estouro financeiro aplicando Service Control Policies via Lambda e EventBridge.

Data & Analytics

02. Cost Explorer Report

Geração mensal automatizada de fatura e créditos líquidos baseada na API do Cost Explorer, gerindo entrega limpa e segura com S3 e SNS.

Security Audit

03. Sophos Inventory Reconciliation

Integração de APIs externas na rotina de auditoria interna para construir uma trilha viva no S3 identificando servidores desprotegidos.

IaC Factory

04. Terraform PoC Factory

Arquitetura de isolamento padronizado para provisionar Data Science (Bedrock) com esteiras restritas de uso diário (Auto Start/Stop).

Privacy & IAM

05. Secure Data Ingestion

Mapeamento de Zona Fria de dados para remoção de PII sensível mediante integração segura Cognito/S3 barrando acessos desclassificados.

Networking

06. Multi-Account VPN

Adaptação crítica de rede corporativa estabelecendo túneis IPsec (Libreswan) no enquadramento AL2023 operado sem borda ativa de SSH.
